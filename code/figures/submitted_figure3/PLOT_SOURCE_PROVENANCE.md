# Figure 3 plotting-source provenance

`FIGURE3_PLOT_SOURCE.tsv` contains the 12 retained plotting records used by `draw_figure3.py` to regenerate the submitted Figure 3. Both are provided under separate file-scoped terms: the plotting code is MIT and the aggregate plotting records and authored figures are CC BY 4.0. These 12 rows were assembled from the authors' controlled analysis records; they are **not** original SNP-level GWAS data, and running the plotting program does **not** independently re-estimate the genetic model.
