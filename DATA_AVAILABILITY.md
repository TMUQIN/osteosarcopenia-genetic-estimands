# Data availability and third-party sources

The original GWAS data remain with the cited source studies and catalogues (see manuscript Table 1 and Supplementary Table S6a). Any public distribution of derived TSVs and figures is conditional on rights review, source attribution and author approval. The FULL staging variant contains aggregate, model-derived summaries and plotting inputs rather than original variant-level GWAS/VCF data. The CODE_ONLY variant intentionally excludes the nine selected derived TSV/SVG objects pending approval. Neither variant includes full model matrices or participant-level data.

For FN-BMD/LS-BMD, exact harmonized-Z file ancestry, release identifier and marker-specific effective N are not established in the retained evidence. See the submitted supplementary methods for the actual source boundaries.
