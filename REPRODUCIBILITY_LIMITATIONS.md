# Reproducibility boundaries

This archive provides selected reproducible *visualization* and numerical verification materials. The FULL variant enables Figure 3 plotting from its retained 12-row source table. Public scripts do not repeat the original GWAS, LDSC, or GenomicSEM model fits. The archived R verification script refers to controlled historical model inputs; those inputs, original genotype/summary statistics, full S/V/I/N matrices, and RDS objects are excluded. Neither left/right model represents an independent replication of shared GWAS inputs. Assumed-N variants are numerical sensitivities rather than biological replications.

The repository's `smoke_test.py` is a structural and path-hygiene check. The FULL content validator checks selected summary table relationships; neither test demonstrates end-to-end scientific replication.
